# Chennai Arabic Institute website

Static website for [chennaiarabicinstitute.com](https://chennaiarabicinstitute.com/), hosted on GitHub Pages.

- `index.html`: the whole site (one page)
- `styles.css`, `app.js`: styling and small interactions
- `assets/`: logo, photos and client logos
- `CNAME`: the custom domain for GitHub Pages

To update the site, edit the files and push to `main`; GitHub Pages republishes automatically.

Placeholders still to fill in `index.html` (search for `PLACEHOLDER`): social profile links and a third review card.
